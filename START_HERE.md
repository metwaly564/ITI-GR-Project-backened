## ⚡ Super Quick Start (3 Steps)

```bash
# 1. Clone and restore
git clone <repository-url>
cd ITI-GR-Project-backened
dotnet restore

# 2. Update appsettings.json with your SQL Server
# Edit: ConnectionStrings:DefaultConnection

# 3. Run!
dotnet run
```

**Open**: http://localhost:5062/swagger

**Done!** 🎉

## 🆘 Having Issues?

| Problem | Solution |
|---------|----------|
| Can't connect to database | See **[CONNECTION_STRING_GUIDE.md](CONNECTION_STRING_GUIDE.md)** |
| Port already in use | `taskkill /F /IM dotnet.exe` then `dotnet run` |
| Tables not created | `dotnet ef database drop --force` then `dotnet run` |
| Need help with APIs | See **[POSTMAN_GUIDE.md](POSTMAN_GUIDE.md)** |
| Any other issue | Check **[README.md](README.md)** Troubleshooting section |
